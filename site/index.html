Built with Think, Reason, Learn

Think, Reason, Learn is an open-source Python library for building prediction models that show their reasoning. It keeps the shape of decision trees, forests and rule sets and lets each step ask a language model to reason, so every prediction comes with the rules behind it. It comes from Vela Research, the research arm of Vela Partners, working with the University of Oxford.

$ pip install think-reason-learn

Python 3.13 or newer, MIT licence. View on GitHub

The toolbox

  • GPTree, decision trees whose questions a language model writes
  • Random Rule Forest, many yes or no questions combined into one transparent model
  • Policy Induction, short policies learned from examples that a person can check
